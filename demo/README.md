# Delivery Ledger live demo

The video in this directory records a real Mermail MCP workflow executed against a dedicated verification mailbox. It shows OAuth catalog discovery, mailbox provisioning, controlled message delivery, metadata-first search, a bounded safe body read, evidence classification, and the refusal to treat an email payment claim as confirmed earnings.

The demo uses synthetic messages sent only to `delivery-ledger-x3@mermail.app`. The claim URL uses the reserved `.invalid` top-level domain and is never opened.
