# Report Card Draft Agent

## What this skill enables
This skill helps teachers save 4+ hours every term by automatically drafting personalized report card emails for all students. Instead of typing 30 individual emails, Mr. Victor's agent reads the results email and writes the first draft for parents.

## How it interacts with Mermail
1. **Mermail Inbox**: The agent reads the forwarded results email from the teacher's Mermail inbox
2. **Agent Brain**: The agent extracts student names, subjects, scores, and performance notes
3. **Agent Drafts**: The agent creates one personalized draft email per student in the drafts folder for teacher review

## Workflow
Step 1: Teacher compiles student results for English, Phonics, and General Knowledge into one email and forwards to their Mermail inbox
Step 2: Teacher opens Mermail and prompts the Agent: "Draft report cards for all students from the latest email"
Step 3: The Agent reads the email and extracts all student data
Step 4: The Agent drafts a personalized email for each student mentioning their scores in English, Phonics, and General Knowledge
Step 5: The Agent saves all drafts. Teacher reviews and clicks "Send"

## Example Prompts
"Agent, I just forwarded Term 2 Results. Please draft report cards for all students in English, Phonics, and General Knowledge."

## Expected Results
- 1 draft email is created for each student
- Each email includes: Parent greeting, Student name, Scores for English, Phonics, General Knowledge, 2 personal comments like "Excellent, nice work" or "Needs to pay more attention", Teacher signature: Mr. Victor
- All drafts are saved and ready for the teacher to review and send
