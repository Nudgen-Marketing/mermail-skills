# Mermail Inbox Triager

Checks the inbox, sorts emails into Urgent / Needs Reply / Informational / Newsletter, and drafts a reply only for items that need one. Never sends automatically — drafts wait for user approval in the mailbox.

Example prompt: "Check my inbox and tell me what needs my attention."
