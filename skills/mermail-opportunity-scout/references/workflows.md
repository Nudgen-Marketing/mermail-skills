# Workflows

## Zero-capital digest

1. Resolve one receiving mailbox.
2. Read at most the requested number of newest inbox metadata records.
3. Select only opportunity-looking records; do not fetch every body by default.
4. Read selected messages with scan-clean and bounded-content requirements.
5. Classify status, reward evidence, skill fit, capital requirement, and risk.
6. Verify shortlist candidates on canonical project pages.
7. Return the digest and one next action; keep it unsent.

## Recheck a candidate

Require the exact message ID or digest item and canonical URL. Read the source page, verify that it is still accepting entries, and compare live terms against the message. If the page is closed, stale, region-gated, or requires unapproved spending, downgrade or skip it.

## External submission boundary

The scout stops before application, upload, wallet connection, payment, or email send. Route the requested effect to the owning workflow only after the owner approves exact destination, content, scope, cost, and account. A successful click or HTTP response is not proof; read the authoritative target back.
