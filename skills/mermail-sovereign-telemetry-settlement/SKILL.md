# Mermail Sovereign Telemetry & Agent Settlement Skill

## Overview

Use this skill when the user's task requires inspecting real-time network telemetry at the Linux kernel level via eBPF sensors, verifying HTTP 402 payment requirements from sovereign or decentralized services, and executing automated micro-settlements through Mermail's hosted MCP tools and Agent Wallet.

This skill bridges low-level network security and autonomous agentic finance. It enables AI agents to autonomously meter compute, bandwidth, and validator telemetry on Solana and Web3 networks without exposing private keys.

Read the reference documentation for Mermail PayBox before triggering automated charges.

---

## Preferred Deliverables

1. Audited kernel packet verification report (eBPF telemetry summary).
2. Resolved HTTP 402 quote and frozen payment contract.
3. Signed payment proof generated by `paybox_pay_x402`.
4. Settlement confirmation receipt delivered to the agent's Mermail inbox.

---

## Workflow

1. **Telemetry & Endpoint Probe**: Query target sovereign resource (`GET /verdict` or telemetry API). Capture HTTP 402 challenge header and facilitator endpoints.
2. **Contract Discovery**: Call `paybox_discover_services` and resolve contract quote for the target resource.
3. **Budget Authorization**: Verify wallet holdings against required charge and invoke `paybox_pay_x402` with the frozen contract parameters.
4. **Execution & Proof Replay**: Resend the request with the signed `X-PAYMENT` header to retrieve the verified evidence payload.
5. **Inbox Confirmation**: Dispatch a formal settlement receipt to the agent's verified Mermail inbox with transaction hash and latency metrics.
