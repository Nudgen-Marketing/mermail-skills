# Job folder template

Copy this folder per job as `jobs/<slug>-<shortid>/`:

- `brief.md` — extracted facts: client, ask, budget, deadline, thread id
- `quote.md` — the scoped quote sent (or drafted): deliverable, price, turnaround, exclusions
- `deliverables/` — work products, attached to the delivery mail
- `receipts.md` — wallet receipts matched to this job (amount, sender, receipt ref)
- `state.md` — current state and the evidence for the last transition
