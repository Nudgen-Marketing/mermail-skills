# Mermail Autonomous Bounty Desk

A production-grade Mermail Agent Skill for autonomous RFQ triage, milestone quoting, Agent Wallet (PayBox) escrow verification, and verifiable bounty delivery on Solana.

---

## 🌟 Capabilities

- **Inbound Bounty & RFQ Intake**: Automatically scans Mermail inbox for incoming client RFQs, bounty alerts, and development proposals.
- **Milestone Quote Generation**: Generates transparent USDC milestone pricing and stages drafts for human approval.
- **PayBox Escrow Verification**: Confirms on-chain USDC deposits to the Agent Wallet before task execution.
- **Verifiable Deliverable Dispatch**: Sends completed deliverables with test proofs and GitHub links via Mermail MCP.
- **Solana Payout Settlement**: Prepares human-authorized PayBox transfer proposals for subcontractor payout or bounty claiming.

---

## 🛠️ Usage

Connect Mermail MCP server (`https://console.mermail.app/mcp`) and invoke:

```
Use $mermail-autonomous-bounty-desk to triage my latest client RFQs, check my PayBox escrow balance, and prepare milestone delivery drafts.
```
