## 🛠️ Clarification Response (by Aditya Waghamare)

Thank you for raising this clarification on Issue #224. Here is the official community guidance for participants on the **Build and Demo a Mermail Agent Skill** bounty:

### 1. AI-Assisted Participation (`HUMAN_ONLY` Policy)
- **Allowed:** Using AI coding assistants (e.g., GitHub Copilot, Cursor, LLM-based debugging tools) as assistive productivity tools to write, refactor, or test code.
- **Requirement:** The human entrant maintains full ownership, code review responsibility, and is accountable for the final submission, demonstration, and integration. 
- **Not Allowed:** Fully autonomous agents submitting entries directly on behalf of bots or bypassing human review (`HUMAN_ONLY` ensures a human is steering and validating all output).

### 2. Mermail Test Workspace & API Keys
- Entrants should utilize the sandbox/test environment documented in `CONTRIBUTING_A_SKILL.md`.
- For isolated testing without connecting a personal inbox or funding a mainnet wallet, use the mock environment configurations provided in the repo under `tests/fixtures/` or request a test API key via the official Mermail developer onboarding channel listed in the repository documentation.
